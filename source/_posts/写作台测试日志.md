今天给博客做了一个「写作台」，用来代替以前在终端里敲命令的发布方式。

## 为什么做这个

博客原本放在 `C:\Windows\System32\qiuqq`，那是 Windows 的系统保护目录，账户对它只有读取权限。所以每次更新文章，都得用管理员身份的终端才能操作，很麻烦。

现在博客搬到了 `C:\Users\QiuQQ\Blog`，并且有了写作台：写好标题和正文，点一下「发布到网站」，剩下的自动完成。

## 这篇日志是怎么发出来的

这一篇不是手动敲命令发上去的，而是走写作台自己的发布流程：

1. 写作台把标题、日期、分类、标签和正文拼成 Markdown 文件，写进 `source/_posts`
2. 自动执行 `git add` 和 `git commit`
3. 自动执行 `git push`，通过 SSH 推送到 GitHub
4. Netlify 检测到仓库更新，自动重新构建并上线

## 验证结果

- 文章能否正确写入 —— 通过
- Markdown 预览能否正常渲染 —— 通过
- 图片粘贴和拖拽上传 —— 通过
- 提交与推送 —— 通过
- 网站自动更新 —— 通过

看到这篇文章出现在网站上，就说明写作台可以正常用了。
